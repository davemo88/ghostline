Simple RTS

1 v 1 mode (human player or Claude player) Claude should be able to play, e.g. via a slow-mode pseudo-turn-based mode. The only mode is 1v1

Each player has a Commander Unit, all it does is build stuff. The player primarily controls the commander unit to explore the map and build buildings.

Victory is capturing / destroying the enemy’s Commander. Each player starts with a base building.

Building stuff - the player can build the following types of buildings:
Defensive - attack enemy units (e.g. tower defense)
Unit production - produce units which attack the enemy’s units and structures
Resource collection building (on/near resource)
Utility buildings - special effects, buffs, etc

Controlling Units
Players cannot control normal units directly. The player can only control the Commander unit. The commander is always selected - the player can only control the command and use it to build + change options on building.
Unit production buildings have associated rally points. Units spawned from those buildings move and auto-attack/engage from the buildings to the rally points
The commander unit has to be physically near any building to control it, e.g. to change a rally point, the commander has to go to the building with that rally point.

Behaviors
Player can set behaviors for the units AI, e.g. stick together, all out aggro, run away, defend the base, etc

Terrain stuff - the maps should have terrain where different regions have different properties, e.g. elevation / cliffs, movement speed, combat buff/debuff,

Upgradeable units / tech tree - the player can spend resources on upgrading a tech tree which gives them stuff

Capture points - give resources/time, buffs, debuffs,

Aesthetics - low poly ghost in the shell inspired universe
